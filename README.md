## 🌍 About Tripora

**Tripora** is a modern travel planning and community platform designed to make travelling easier, smarter, and more organized.

From discovering destinations and planning trips to managing schedules and interacting with fellow travellers, Tripora brings essential travel features together in one place.

The platform also provides an **Admin Dashboard** for managing users, monitoring activity, analyzing destinations, and moderating the travel community.

---

## ✨ Features

### 🏠 Travel Experience

* 🌍 Explore travel destinations
* 🗺️ Discover places and attractions
* ❤️ Save favourite destinations
* 📋 Organize upcoming trips
* 📍 View destination information
* 🔎 Search and discover places

### 📅 Trip Calendar

* View trips using a calendar
* Navigate between months

# 🚀 Getting Started

Follow these steps to run Tripora locally.

## 1. Clone the Repository

```bash
git clone https://github.com/jalpatel2646/Tripora.git
```

Move into the project:

```bash
cd Tripora
```

---

## 2. Install Frontend Dependencies

```bash
cd frontent
npm install
```

---

## 3. Start the Frontend

```bash
npm run dev
```

Open the local URL displayed in your terminal.

Usually:

```text
http://localhost:5173
```

---

## 4. Backend Setup

Move to the backend directory:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

Start the backend:

```bash
npm run dev
```




Pull the latest changes again before pushing:

```bash

```

Then push:

